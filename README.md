# Pine Script Repository

Dieses Repository dient als Ausgangspunkt für das Entwickeln und Organisieren von Pine-Script-Indikatoren und -Strategien für TradingView.

## Struktur

```
scripts/
  moving_average_crossover.pine
```

- `scripts/` enthält alle Pine-Script-Dateien. Weitere Skripte können hier abgelegt werden.
- `moving_average_crossover.pine` ist ein Beispielindikator für ein einfaches EMA-Crossover mit Alerts und visuellen Signalen.

## Nutzung
1. Öffne TradingView und erstelle ein neues Pine-Script.
2. Kopiere den Inhalt der gewünschten Datei aus `scripts/` in den TradingView-Editor.
3. Passe Parameter und Logik nach Bedarf an.

## Beitragende
- Pull Requests mit neuen Skripten oder Verbesserungen sind willkommen.
- Bitte halte dich an sprechende Dateinamen und dokumentiere Änderungen im Skript als Kommentar.

Viel Erfolg beim Entwickeln neuer Pine-Script-Strategien!
